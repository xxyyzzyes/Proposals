Antigravity Architecture

Google Antigravity 进阶实操技巧指南

通过多智能体协作、深度规划与自主验证，大幅提升高难度任务的开发效率与代码质量。

🔍 规格挖掘与前置规划
/grill-me [任务描述] 主动审问需求

面对复杂度高、易有逻辑盲点的需求时，促使 Agent 暂停编写代码，反客为主向开发者连续提问，并为每个技术细节附带推荐答案，提前逼出边界条件与异常状态。

/plan [任务描述] 强制产出实作蓝图

要求 Agent 在修改前深入扫描代码库并产出结构化的实施计划书（Implementation Plan），待人工确认架构变动与文件影响范围后，再启动代码改写。

🚀 深度攻坚与多 Agent 协同
/boost [任务描述] 呼叫子 Agent 深度推理与攻坚

面对高复杂度并发缺陷、死锁、竞态条件、隐蔽回归缺陷或深层跨文件重构，突破单轮对话限制，在后台自动生成并派发专业子 Agent 战队（如负责全域巡检与根因攻防的 DeepInvestigator、专注底层实现与严密约束的 DeepCoder）。通过 Supervisor Loop 多层级调度，让子 Agent 相互交叉验证、博弈校验并闭环输出高质量解决方案。

/teamwork [任务目标] 分布式自主 Agent 团队协作

当项目规模庞大、涉及多模块独立开发或大规模重构时，自动组建包含架构设计、全栈编码与测试审查等多角色的自主 Agent 团队。在平行的隔离工作区分头攻坚并自动合并成果，实现团队级人效扩展。

🛡️ 自主验证与除错技巧
/browser 启动浏览器 Subagent 实测

针对前端与全栈应用，自动调起无头或可见的 Chrome Debugging 会话。AI 自主点击界面、监控控制台错误及网络请求，实现端到端的缺陷复现与回归校验。

/goal 闭环自治直到验证通过

赋予 Agent 自主执行权限，使其持续进入“执行测试 ➔ 捕获 Log ➔ 修复代码”的自动化循环，直至所有既定验收条件全部通过，免去反复手动确认。

🧠 上下文优化与规则沉淀
/learn [指导原则] 经验固化为永久 Skill

将当前会话中纠正的编码规范、设计模式或规避策略自动提取并写入工程目录下的技能规范（如 SKILL.md）。后续会话按需渐进加载，防止重复踩坑且不虚耗 Token。

/btw [旁支问题] 隔离临时提问

在攻坚主流程中临时查询函数定义、API 规格或数据库结构时，开辟隔离通道执行，返回结果后不占用也不污染主开发任务的上下文内存。

⚖️ 实验分支与成本控制
/fork 或 /branch 平行方案探索

遇到架构分歧或多重重构路径时，在关键节点克隆出独立会话分支。可分别尝试不同的技术路线（如方案 A 与方案 B），对比最优产出而互不干扰。

/effort [low|medium|high|max] 动态推理精力

手动调节 Gemini 3.8 Flash 的思考步数配额。常规 CRUD 或样式修改设为 low 以控制 Token 消耗；核心算法与并发重构则设为 high 或 max。

⚡ 任务调度与会话维护
/schedule [周期或定时] 定时与周期性后台自动化

设定单次定时唤醒（Timer）或基于 Cron 表达式的周期性巡检任务（如每日代码构建巡检、依赖更新扫描或定期生成总结报告）。任务在后台静默执行，并在完成或触发告警时主动通知。

/compact [保留重点] 智能压缩会话上下文

长时间长会话开发容易累积大量冗余 Log 与 Token。使用该指令触发系统级上下文提炼，将关键决策、架构共识与待办事项无损压缩固化，快速释放 Context 窗口并降低后续推理延迟。
